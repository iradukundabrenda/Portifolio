Voice Library

Voice-Activated Book Search

This project was an exciting exploration into the intersection of voice recognition and web application development. My goal was to build an interactive system that allows users to search for books using their voice and receive instant audio feedback.

The project implements a Flask-based web app that integrates SpeechRecognition for capturing spoken input and pyttsx3 for text-to-speech output. Users simply speak the name of a book — the system recognizes the query, searches the library database, and responds audibly with confirmation.

Performance was evaluated by testing recognition accuracy, response time, and user experience smoothness. Challenges included handling variations in pronunciation, ensuring accurate speech-to-text conversion, and maintaining seamless audio playback. Despite these challenges, the project demonstrates a functional, user-friendly system that bridges voice technology with interactive web applications — with clear potential for expansion into fully voice-driven library or e-learning systems.

Education Technology · Full-Stack

EduTrack

Student Progress Tracking Platform

EduTrack is a full-stack education management platform built to give students and educators a clear, real-time view of learning progress. The goal was to replace scattered spreadsheets and manual tracking with a unified, data-driven dashboard.

The backend exposes a structured REST API handling user authentication, course enrollment, progress updates, and activity logging. The frontend consumes this API to render a clean dashboard with per-course progress bars, activity feeds, and completion statistics.

Building EduTrack required designing a relational database schema that handles many-to-many relationships between students and courses, alongside a clean separation between the API layer and the UI. The project deepened my thinking around data modelling, state synchronization, and building systems that scale gracefully as usage grows.

Picasso

Browser-Based Creative Drawing Application

Picasso is a browser-based creative drawing tool built entirely with the HTML5 Canvas API. No plugins, no frameworks, no downloads — a full-featured paint application running entirely in the browser.

The core challenge was building a responsive, stateful drawing engine — handling multiple tools (pencil, fill, eraser), colour selection, brush sizing, undo history, and real-time rendering while keeping the interface fluid and performant. Every tool required its own rendering logic, and managing canvas state without memory bloat demanded careful architectural thinking.

Picasso demonstrates an ability to build complex, real-time interactive interfaces that go far beyond static pages. The kind of technical depth that doesn't show up in a screenshot but is immediately clear the moment you start drawing.
